# ServexaPro

Device Service Management — clean CRM front-end demo.

## Live preview
Once GitHub Pages deployment is enabled and has completed:
https://abdullahalhassan1800-glitch.github.io/ServexaPro/

## Deployment
This repository includes a GitHub Actions Pages workflow at `.github/workflows/pages.yml`. In the repository, open **Settings → Pages** and confirm **Build and deployment → Source: GitHub Actions**. Check the **Actions** tab for the deployment run.

This is a front-end demo with sample data. It does not yet include a shared database, user authentication, or connected service integrations.
